# RUSONG TV: автоматизация эфира

1. **Supabase (один раз).** В Supabase проекта RUSONG → SQL Editor выполните `admin/supabase-live.sql` (нужна функция `is_admin()` из `admin/supabase-schema.sql`).
2. **Админка → «Эфир».** Загрузите файл проекта из Resolve (EDL с маркерами или клипами, FCP7 XML, FCPXML, OTIO, TXT), проверьте таблицу, «Выйти в эфир». Сайт обновится сам, без GitHub. «Консоль» — те же действия командами (`help`).
3. **Виджет «Сейчас в эфире»** добавлен на главную под плеером; без данных скрыт.

## Заставки программ
Распознаются по имени файла клипа или маркера: Baby Time, Bridge in Time, Retro Dance, Rock Party Time, Movie Time, Wake Up Call. Роль определяется сама: первая — начало, последняя — конец, после рекламы — возврат, перед рекламой — уход, остальные — переход. Явно: `Movie Time — конец`, `Wake Up Call: на рекламу`, `Retro Dance: возврат`. Рекламу в маркерах отмечайте `[реклама]`.

## Локально (необязательно)
`scripts/` + `start_gui.bat` — то же в окне на компьютере (Python 3). Повторы (`update_repeats.py`) для RUSONG не настроены — нужен VK-сообщество канала.
